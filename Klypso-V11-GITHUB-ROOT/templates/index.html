Ce que KLYPSO fait, concrètement.

Est-ce que KLYPSO est utilisable sans abonnement ?

Oui. Le compte Free permet déjà d'ouvrir le workspace et d'utiliser le cœur du workflow. Les capacités d'IA avancées restent réservées aux offres supérieures.

Qu'est-ce qui se passe après l'import d'une VOD ?

Le projet est créé, le média est enregistré puis KLYPSO prépare l'analyse et les étapes suivantes du workflow.

Est-ce que je dois tout faire automatiquement ?

Non. L'objectif est de pouvoir partir d'une analyse puis reprendre la sélection, le montage, l'identité et l'export manuellement.

Mes réglages visuels sont-ils conservés ?

La personnalisation du workspace est enregistrée sur l'appareil pour retrouver les matières, couleurs et préférences choisies.
